# หน้าจัดการรถบัส

ปรับเฉพาะหน้าตาและการอ่านข้อมูลทั้ง 2 แถบ โทนสีอ้าง --claude-* ของระบบเดิม
ไม่มีการเปลี่ยนสูตรรอบ/สถานะจาก backend ไม่มี SQL ไม่มีการเขียนข้อมูลจริงหรือ Deploy

## ทะเบียนรถ

- สรุป 4 ค่าเป็นการ์ดแยกแบบเมนู Stock: ทะเบียนทั้งหมด อยู่ระหว่างซ่อม รออะไหล่ และพร้อมใช้งาน
- ช่องค้นหาพื้นขาว พร้อมสลับตาราง/การ์ด และจำนวนผลลัพธ์ที่พบ
- ตารางกำหนดสัดส่วนคอลัมน์ให้เลขคัสซี/รุ่นยาวไม่เบียดสถานะและปุ่ม
- บนมือถือ ตารางเป็นรายการสองคอลัมน์ต่อคัน ส่วนการ์ดยังคงใช้งานได้
- ปุ่มประวัติ แก้ไข เพิ่ม และลบยังเรียกการทำงานเดิม ไม่มีการแก้ workflow

## ติดตามเปลี่ยนถ่าย

- รูปแบบหัวข้อ สรุป และช่องค้นหาเป็นชุดเดียวกับทะเบียนรถ
- รวมทะเบียนกับกลุ่มรอบ และรวมโปรแกรมถัดไปกับไมล์ครบกำหนด เหลือ 8 คอลัมน์
- เน้นไมล์ปัจจุบันด้วยตัวเลขใหญ่ขึ้น แยกวัน/ที่มาเป็นข้อความรอง
- กดเลขใบงานเปลี่ยนถ่ายล่าสุดเพื่อเปิดเมนูแจ้งซ่อมพร้อมกรองใบงานนั้น
- ปุ่มข้อมูลใช้ไอคอนบนคอมพร้อม tooltip/accessible label และมีข้อความบนมือถือ
- สถานะ/คำอธิบาย วันอ้างอิง HR-POS และวันที่ใบงานยังแสดงตามข้อมูลเดิม
- ช่องที่ยังไม่โหลด/โหลดไม่สำเร็จแสดง “—” ในสรุป ไม่แสดงเป็น 0
- ไม่เพิ่มแถบสีเหลืองด้านบนกลับมา

## ทดสอบ

เปิด run-local.bat ตามเดิม แล้ว Ctrl+F5 เพื่อรับ CSS/JS/HTML ล่าสุด
ใช้ข้อมูลจำลองในการทดสอบ UI:

```powershell
node build.js
# เมื่อ NODE_PATH มี Playwright
node tests/fleet-browser.test.js
node tests/oil-tracking-browser.test.js
node tests/oil-dashboard-browser.test.js
```

ตรวจที่ 360/390/430/768/1024/1440px รวมชื่อรุ่นยาว ค้นหา สลับมุมมอง
ตัวกรองสถานะ ที่มาข้อมูล และลิงก์ใบงาน ไม่มีการอ่าน/เขียนฐานข้อมูลจริงใน browser tests
ภาพตัวอย่างอยู่ใน tmp/fleet-ui/
